# JC3248W535C — Calendar v4 (тестовый исходный проект)

Создано **на основе заработавшего Calendar v3**. Сохранены драйвер дисплея AXS15231B, пины, работа с сенсором, параметры PlatformIO `qio`, `80 MHz`, `qio_opi`. Для объединения бинарника в GitHub Actions сохранены параметры **DIO / 40 MHz**, благодаря которым у пользователя запустилась v3.

## Что нового

- 5 разделов: календарь, часы, погода, таймер и Wi-Fi/настройки.
- Погода через Open-Meteo, без API-ключа: температура, ощущаемая температура, влажность, ветер, условия; обновление раз в 20 минут. Требуется доступ к интернету.
- В браузере можно выбрать город *и координаты* погоды, часовой пояс, Wi-Fi. По умолчанию — Санкт-Петербург, UTC+3. Город вводится вручную, координаты тоже (автоматический поиск города пока не реализован).
- Настройки доступны по адресу `http://<IP-адрес-устройства>/` при подключении к домашней сети. Или включите `CALENDAR-SETUP` на экране **Сеть** и зайдите на `http://192.168.4.1`; пароль точки — `calendar123`.
- Старые параметры Wi-Fi в Preferences остаются при обновлении, если не стирать всю flash/NVS.

## Компиляция

1. Замените содержимое репозитория файлами из архива, включая `.github/workflows/build.yml`.
2. В GitHub: **Actions → Build JC3248W535C Calendar v4 → Run workflow**.
3. При успешной сборке скачайте артефакт `JC3248W535C_CALENDAR_V4_fullflash`; он содержит `.bin`.
4. Загрузите merged/fullflash `.bin` **с адреса `0x0`**, как и удачный образ v3.

**Этот архив — исходники, а не бинарник. Компиляция и запуск v4 в аппаратуре ещё не проверены.** Перед прошивкой сохраните рабочий `.bin` v3. Не переключайте проект на параметры объединения QIO / 80 MHz — они вызывали сбой загрузки в v3.

## Оговорки

- Разрешение и ориентация **320 × 480 (вертикально)**, чтобы не менять проверенную аппаратную инициализацию.
- Данные погоды запрашиваются через HTTPS у Open-Meteo. Ради простоты публичного запроса проверка сертификата в этой тестовой версии отключена — **в запросе нет логинов или паролей**.
- Для погоды используется ручной ввод географических координат, автоматического определения города нет.
- Это не ESPHome: сборка Arduino/PlatformIO.
